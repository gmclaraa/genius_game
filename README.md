# 🎮 Genius

Projeto desenvolvido para praticar JavaScript, trabalhando com manipulação do DOM, eventos, temporizadores e áudio.
A aplicação recria o clássico jogo Genius (Simon), onde o jogador deve repetir uma sequência de cores que aumenta a cada rodada.

## 💻 Sobre o projeto

A proposta foi recriar o clássico jogo Genius (Simon), onde o sistema gera uma sequência aleatória de cores que o jogador precisa repetir corretamente, clicando nos pads na ordem exibida.

A cada acerto, uma nova cor é adicionada à sequência, aumentando a dificuldade. O jogo conta com efeitos sonoros para cada pad, contador de pontuação e modo estrito (strict), que reinicia a pontuação sempre que o jogador erra.

## 🔍 Funcionalidades

- Ligar/desligar o jogo (switch on/off)
- Iniciar uma nova partida
- Gerar sequência aleatória de cores a cada rodada
- Tocar som correspondente a cada pad
- Exibir contador de pontuação
- Ativar modo strict (reinicia ao errar)
- Reset automático após 5 segundos de inatividade do jogador
